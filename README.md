# Wedding Invitation Website

Open `index.html` in a browser to view the invitation.

Edit all names, date, time, venue, map link, messages, countdown date, music path, and gallery images in `script.js`.

Background music is included as:

```text
assets/music.wav
```

For WhatsApp sharing, upload the whole folder to hosting first. WhatsApp reads the preview image from `assets/og-cover.jpg`.
